# Generated Analysis Outputs

This directory stores files generated by the reproducible analysis pipeline.

The generated CSV files are intentionally excluded from version control because they can be reconstructed from the experiment results.

Run:

```bash
python -m analysis.run_all --results /path/to/experiment/root --strict
```

The pipeline generates:

```text
analysis_outputs/
├── run_manifest.csv
├── run_manifest_missing_eval.csv
├── auc/
│   ├── auc_by_seed.csv
│   └── auc_by_run.csv
└── normalized/
    ├── auc_by_seed_normalized.csv
    ├── auc_by_run_normalized.csv
    ├── relu_baseline_by_task.csv
    └── paired_seed_rows.csv
```

For the complete reported study, the validated pipeline processes 14,080 seed-level runs and produces 13,920 exact candidate-versus-ReLU seed pairs with zero missing matches.
